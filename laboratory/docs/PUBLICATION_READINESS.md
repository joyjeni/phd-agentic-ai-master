# Publication readiness

Honest assessment of the four GitHub research modules plus this integrated
laboratory. **None of the objectives is a slam-dunk accept at a top-IF venue
today.** They are named algorithms with citable SOTA papers. The remaining gap
is experimental scale, claim/code alignment, and statistical reporting.

The **research proposal** does not convert that gap into NDCG, latency, token,
or accuracy targets. Proposal-stage evidence is architectural completeness and
live Indian OGD pipeline integrity.

| Code | Module | Plausible venue *after* experiments match claims | Ready now? |
|------|--------|---------------------------------------------------|------------|
| O1 | SATR | ACL/EMNLP Findings, SIGIR short | No |
| O2 | APRR | AAMAS / ICLR workshop; ACL with a MasRouter bake-off | No |
